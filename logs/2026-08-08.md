# 2026-08-08 AI Work Checkpoints

## [[ai-work-next-action-checkpoints]] - AI Work Checkpoints

A simple A/B/C pattern for AI work across sessions: identify the next action, record it in a repo-local `NEXT.md`, and pull checkpoints into a central planning view; GitHub remains optional for shared tracking.

## [[scheduling-claude-sessions]] - Scheduling Claude Sessions

Four ways to start a Claude Code session later — in-session `CronCreate`, `/loop`, durable cloud routines via `/schedule`, and OS cron/launchd with headless `claude -p` — and which survive quitting the terminal.
