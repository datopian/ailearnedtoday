# Way Into AI rename design

## Goal

Rename the site and repository-facing documentation from AI Learned Today to Way Into AI, positioning it as a practical guide for developing AI capability.

## Approved change

- Use **Way Into AI** as the site and repository name, with the tagline **From curious to capable.**
- Retain `assets/ailearnedtoday-logo.webp` as the existing AI navigation mark until a replacement asset exists.
- Make `https://wayintoai.com` the canonical website reference and `https://github.com/datopian/wayintoai` the GitHub destination.
- Refresh the homepage from a learning-in-public diary to concise practical-guide positioning while retaining its posts, logs, and newsletter sections.
- Keep the existing Substack address and embed in place, but refer to it as the Way Into AI newsletter.
- Update active project documentation and command examples; preserve historical mentions in reference entries and logs.
