# ui.sh

Agent skills for interface builders, from the people behind Tailwind CSS and Refactoring UI.

![ui.sh](https://screenshotit.app/https://ui.sh/)

- **Website**: https://ui.sh/

## Overview

ui.sh is an invite-based collection of task-oriented prompts and workflows for building better interfaces with AI coding agents. It packages design judgment into reusable "skills" focused on concrete UI work rather than generic prompting.

The initial skill set covers new UI design, generating multiple design directions, brand kits, componentization, Tailwind class cleanup, thoughtful dark mode, responsive design, dark-mode image adaptation, and converting screenshots or wireframes into semantic markup.

**Think**: Refactoring UI as agent skills - practical design taste and workflow guidance that can be handed directly to a coding agent.
