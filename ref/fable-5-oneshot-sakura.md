# SAKURA - Ink & Bloom

Scroll-driven Japan-themed landing page demo built with Fable 5 and a set of generated videos.

![SAKURA - Ink & Bloom](https://screenshotit.app/https://oneshot-sakura.vercel.app/)

## Links

- **Website**: https://oneshot-sakura.vercel.app/
- **Reddit**: https://www.reddit.com/r/vibecoding/comments/1uloakf/fable_5_oneshot_ability_is_crazy/

## Overview

This project is a showcase for a one-shot Fable 5 build: a polished landing page with a Japanese visual theme, scroll-driven sections, animation-heavy presentation, and video assets that the author says were generated by them. The Reddit discussion frames it as an unusually strong result from a low-reasoning, no-skills workflow.

## Example

> "We are sooo back, fable is here again."

The post says the site was built in under 30 minutes and claims the result came from a single prompt rather than a step-by-step engineering process.
