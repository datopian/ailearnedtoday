## [[changelog-convention]] — Canonical changelog convention for AI-native repos

Rufus's `life-itself/changelog`: one markdown block pasted into a repo's `AGENTS.md`, with a fuller `CONVENTION.md` fetched only at drafting time. Agents draft an entry at session-checkpoint, weighted to a three-tier scale (skip / one sentence / full writeup); one file per `changelog/YYYY-MM-DD-slug.md`. Built because no good changelog skill exists yet.
