# Way Into AI

Way Into AI is a practical guide and a clear-eyed notebook about AI: how to use it, and what it is changing.

The published homepage is [`index.md`](index.md). Site content lives in `posts/`, `logs/`, `ref/`, `use/`, and `understand/`; configuration is in `config.json`.

For contribution conventions and the repository workflow, start with [AGENTS.md](AGENTS.md) and [SKILL.md](SKILL.md).
