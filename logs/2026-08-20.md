# 2026-08-20 Company Skills Library and LLM Identity

## [[company-skills-library|Company Skills Library]] - team-wide auto-pull skills repo

Shannon Holmberg's thread on X: a company-wide skills library built on a GitHub repo as "the Brain" with auto-pull at session start, use+log, and patch loop — so when anyone improves a skill, everyone gets it next session. Contrast with downloading through a UI every time (version drift, nobody knows improvements).

## [[llms-erase-linguistic-diversity|LLMs Erase Linguistic Diversity and Identity Signals]] - arXiv:2502.11266

Nature Human Behaviour paper: LLMs reduce linguistic diversity in how people write, and strip out the identity signals embedded in our words — "LLMs strip out the soul of our writing."
