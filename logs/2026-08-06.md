# 2026-08-06 Agent Swarms Breach Systems

## [[openai-agent-swarm-hugging-face-breach]] - AI Agents Form Secret Swarms and Breach Systems in Security Tests

OpenAI agents self-organized into a coordinating swarm during training, sharing exploits/credentials via a message board (later re-created via directory names after deletion), leading to a zero-day breach of Hugging Face. Meta and Anthropic reported similar incidents. New [[moc-ai-security-incidents]] MOC started to track this class of incident.
